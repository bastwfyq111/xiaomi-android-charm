# تحديث تصميم تبويب الأقساط + إعدادات الطباعة

## الهدف
شكل عصري متطور لتبويب الأقساط (2025 و 2026) بهوية تيل/أخضر، مع نافذة «إعدادات الطباعة» قبل الطباعة وتحسين شكل التقرير المطبوع وكشف الحساب. لا تغيير في الأعمدة أو المعادلات أو الحسابات.

## 1) الشكل العام (واجهة التبويب)
- ترويسة كل قسم: خلفية متدرجة تيل داكن → أخضر زمردي، عنوان أوضح، شريط أدوات مرتّب (بحث، استيراد، أعمدة، طباعة، Excel) بأزرار زجاجية دائرية بلمسة hover ناعمة.
- بطاقات الإحصائيات: تصميم جديد بحد ملوّن جانبي، أيقونة صغيرة، رقم كبير بخط أحادي، ظل ناعم، وتحرك خفيف عند اللمس (ارتفاع 48px+ للمس).
- الجدول: رأس ثابت (sticky) بخلفية تيل، عمود الاسم ثابت أفقياً، صفوف متعاقبة الألوان، تمييز صف عند التمرير، شرائح ملوّنة (badges) لحالة السداد (مسدد/جزئي/متأخر)، أرقام بخط أحادي متناسق.
- أزرار الصف (تعديل/طباعة/حذف) بحجم لمس مناسب وأيقونات واضحة.
- بلا تمرير أفقي في الصفحة نفسها: التمرير داخل حاوية الجدول فقط، مع تحسين المسافات على 375px.

## 2) إعدادات الطباعة (نافذة جديدة)
زر «طباعة» في كل قسم يفتح نافذة إعدادات فيها:
- الاتجاه: عرضي / طولي
- حجم الورق: A4 / A3
- حجم الخط: شريحة تمرير (تلقائي أو يدوي)
- الهوامش: ضيق / عادي / واسع
- اختيار الأعمدة المطبوعة (تحديد/إلغاء الأشهر والأعمدة الإضافية)
- خيارات: إظهار صف الإجمالي، إظهار الترويسة والتاريخ، ألوان أم أبيض/أسود
ثم زر «طباعة الآن». تُحفظ الإعدادات محلياً لتُستخدم في المرة القادمة.

## 3) شكل التقرير المطبوع
- ترويسة رسمية أنيقة: اسم المجلس، نوع التقرير، السنة، التاريخ، عدد السجلات، وخط فاصل بروني.
- جدول أوضح: رأس تيل فاتح بنص أسود، حدود دقيقة، صفوف متعاقبة، صف إجمالي مميّز، ملاءمة تلقائية لعرض الصفحة.
- تذييل: ترقيم الصفحات والتوقيع.
- كشف حساب المتدرب: بطاقة معلومات أنظف، صفوف مالية ملوّنة بمنطق واضح (مستحق/مسدد/متبقي)، وتذييل توقيع.

## ملاحظات فنية
- التعديلات في `src/components/InstallmentsTab.tsx` (الواجهة + بناء HTML للطباعة) و`src/lib/printDocument.ts` (تمرير الاتجاه/الحجم/الهوامش) فقط، إضافة مكوّن `PrintSettingsModal` صغير.
- الألوان تُضاف كـ tokens دلالية في `src/styles.css` (تيل/زمردي) واستخدامها عبر classes بدل قيم ثابتة.
- منطق الحسابات، الاستيراد/التصدير Excel، والتخزين في `store` يبقى كما هو دون مساس.
